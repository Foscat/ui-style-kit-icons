# Synthwave Style Source Workshop

Working name: **Neon Horizon**

Synthwave should feel retro-futurist, cinematic, and energetic. The icon pack leans into sunset gradients, chrome highlights, and horizon-line motifs while keeping every required icon mapped to the same semantic name.

## Visual Ingredients

| Layer | Direction |
| --- | --- |
| Surfaces | Midnight panels, horizon lines, and soft neon atmosphere |
| Borders | Bright strokes that suggest lit signage |
| Shadows | Magenta and cyan glow, restrained enough for UI use |
| Color | Theme-driven neon roles with warm highlight accents |
| Shape | Rounded tech geometry mixed with retro display cues |
| Icons | Clear app glyphs plus optional synthwave extras for expressive surfaces |

## Things To Avoid

- Purely decorative extras replacing required semantic icons
- Low-contrast neon on light themes
- Large gradients that hide the icon shape
- Unbounded glow that bleeds into adjacent UI
