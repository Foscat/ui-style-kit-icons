# Minimal SaaS Style Source Workshop

Working name: **Quiet Product Console**

Minimal SaaS should feel measured, professional, and efficient. The style is built for dashboards, admin tools, settings views, billing surfaces, and creator/business control panels where clarity matters more than spectacle.

## Visual Ingredients

| Layer | Direction |
| --- | --- |
| Surfaces | Quiet panels, subtle cards, restrained background gradients |
| Borders | Soft 1px token borders, never heavy outlines |
| Shadows | Low elevation, mostly for separation |
| Color | One clear primary action color plus muted secondary structure |
| Shape | Small-to-medium radii, practical pills, balanced card corners |
| Icons | Monoline symbols, light fills, clear silhouettes at small sizes |

## Things To Avoid

- Decorative style-specific objects that do not map to app semantics
- Neon, glass, sticker, or poster effects
- Heavy fills on every interior shape
- Excessive corner rounding
- Dense icon detail that becomes muddy at 16-24px

## Open Workshop Questions

1. Should Minimal SaaS have a no-frame icon variant for dense nav rails?
2. Should icon surfaces inherit card radius exactly, or stay slightly tighter?
3. Should filled status icons use stronger color than ordinary nav icons?
