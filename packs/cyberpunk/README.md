# Cyberpunk Standardized Icons

Theme-aware SVG icon pack aligned to the UI Style Kit icon contract.

- Contract version: `0.1.0`
- Required core icons: `64`
- Included icons: `64`
- Optional extras: `0`

Use the semantic icon IDs consistently across UI styles. Change the active UI style to change the visual language, not the icon name.

```html
<link rel="stylesheet" href="dist/cyberpunk-icon-pack.css">
<svg class="cp-icon cp-icon--lg" aria-hidden="true">
  <use href="#cp-icon-dashboard"></use>
</svg>
```
