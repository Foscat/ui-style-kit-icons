# Cyberpunk Style Source Workshop

Working name: **Neon Control System**

Cyberpunk should feel sharp, electric, and technical while still behaving like a practical app icon set. The pack uses high-energy accents, angled forms, and dark UI contrast without breaking the shared semantic contract.

## Visual Ingredients

| Layer | Direction |
| --- | --- |
| Surfaces | Dark panels, luminous edges, compact tech framing |
| Borders | Bright token strokes with occasional double-line accents |
| Shadows | Controlled glow effects that remain readable in light and dark modes |
| Color | Cyan, magenta, lime, and warning accents mapped through UI Style Kit tokens |
| Shape | Angular cuts, circuit-like marks, precise corners |
| Icons | Recognizable app symbols with cybernetic detail kept inside the silhouette |

## Things To Avoid

- Decorative marks that obscure the base semantic shape
- Glow-only forms without a clear silhouette
- Hard-coded neon colors that cannot follow theme changes
- Excessive detail that fails at small interface sizes
