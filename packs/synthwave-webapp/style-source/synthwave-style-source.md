# Synthwave Web App Style Source Workshop

Working name: **Dashboard Night Drive**

Synthwave Web App is a focused synthwave variant for product dashboards and common web workflows. It keeps the neon horizon language but strips it down so dense app screens stay scannable.

## Visual Ingredients

| Layer | Direction |
| --- | --- |
| Surfaces | Compact dashboard panels with subtle retro-future cues |
| Borders | Crisp lit strokes that work in repeated UI controls |
| Shadows | Short glow effects for focus and state, not decoration everywhere |
| Color | Synthwave accents resolved through UI Style Kit variables |
| Shape | App-native geometry with restrained retro display details |
| Icons | Required web-app symbols only, optimized for repeated navigation and controls |

## Things To Avoid

- Extra lifestyle objects that do not map to web-app semantics
- Overly cinematic treatment on every icon
- Heavy glow that reduces legibility in sidebars or tables
- Diverging from the shared synthwave symbol prefix contract
