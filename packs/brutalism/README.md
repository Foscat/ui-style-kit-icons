# Brutalism Standardized Icons

Theme-aware SVG icon pack aligned to the UI Style Kit icon contract.

- Contract version: `1.0.0`
- Required core icons: `64`
- Included icons: `64`
- Optional extras: `0`

Use the semantic icon IDs consistently across UI styles. Change the active UI style to change the visual language, not the icon name.

```html
<link rel="stylesheet" href="dist/brutalism-ui-style-icons.css">
<svg class="brutal-icon brutal-icon--lg" aria-hidden="true">
  <use href="#brutal-icon-dashboard"></use>
</svg>
```
